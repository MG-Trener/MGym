# Проверки MGym 0.6.0

13.10.2026. Общий источник генератора: `MG-Trener/Gym-150`, commit `310d4a381b27e2db842dde3d516270f3fd0b1c35`, шаблон 4. Вычислительные файлы сайта и APK совпадают побайтно.

- Сайт: 50 тестов JavaScript прошли. Android-копия: 51 тест прошёл, включая перевод новых динамических текстов на восемь языков.
- Матрица из 1944 профилей покрывает возраст 16/35/65/90 лет, три уровня стажа, три варианта регулярности, обычное/ограниченное восстановление, сроки 8/20/32 недели, шаг 1/2,5/5 кг и исходную силу 50/75/140 кг. Проверяются допустимость календаря, развитие нагрузки, согласованность килограммов с повторами/RPE и ограничения максимальных попыток.
- Дополнительно проверены неизвестная сила, слишком тяжёлый гриф, крупный шаг блинов при коротком сроке, соседние тренировочные дни, перенос цели, остановка и возобновление прогрессии, миграция старого плана и пересчёт без повторного начисления прошлого прогноза.
- Два целевых Android UI-теста на Pixel 7, API 37.1 прошли: создание и миграция персонального плана с новой копией; создание длинной программы с полем регулярности, растущими рабочими весами и отображением траектории. Применялся только отдельный пакет `.uitest`, данные основной установки не очищались.
- `:app:assembleDebug`, `:app:testDebugUnitTest`, `:app:lintDebug` прошли. Итоговая обычная сборка выполнялась без тестового package ID.
- В боковом браузере на публичном сайте проверены создание, сохранение, выбор силового блока и обновление ранее сохранённого плана. Ошибок JavaScript не обнаружено. GitHub Pages завершил публикацию; новые файлы проверены на публичном домене.
