## Перед отправкой

Завершить проверку личности, указать настоящий support email, настроить upload key и Play App Signing, собрать подписанный AAB, пройти внутренний/требуемый закрытый тест, проверить pre-launch report и заполнить анкеты. Для ранних установок из GitHub сначала сохранить обе резервные копии. Без этих шагов приложение нельзя считать полностью готовым к модерации.

Target SDK — 37; снижать его до 36 из примера не требуется. [Требования Google Play](https://support.google.com/googleplay/android-developer/answer/11926878) · [Android vitals](https://developer.android.com/google/play/vitals).
