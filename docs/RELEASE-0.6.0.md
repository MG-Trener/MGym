# MGym 0.6.0 — новая модель силовой программы

Переработан общий подход расчёта для жима, приседа и тяги. Исходная оценка силы и условная плановая траектория теперь хранятся отдельно: длинная программа развивает рабочую нагрузку и связывает её с контрольным днём.

- Вход, рабочий объём, развитие силы, силовой этап, разгрузки и подводка составляют один цикл. Вес подхода согласован с повторениями и пределом RPE. У новичков два разнесённых дня включают рабочую и объёмную нагрузку.
- Стаж и текущая регулярность тренировок разделены. Давняя дата рекорда не превращает весь план в возвращение после перерыва.
- Цель оценивается по сроку, стажу, расписанию и восстановлению. Завышенный запрос получает промежуточный ориентир цикла. Возраст учитывается в дозировке; масса тела не подставляется вместо фактической силы.
- Высокий RPE и недобор повторов останавливают будущие плановые прибавки. Пересчёт по факту начинает новую траекторию от даты результата, без повторного начисления прошлого прогноза.
- В календаре видно начало и конец основной рабочей нагрузки. Подсобная работа имеет прогрессию повторов с увеличением веса после верхней границы.
- Существующие планы обновляют будущие дни; записанные подходы сохраняются. Перед обновлением создаётся новая копия, прежние копии остаются доступными.

Коэффициенты планирования раскрыты в [методике](https://mgym.mg-trener.com/method.html). Они задают условные ступени и не являются статистически валидированным прогнозом личного рекорда.

Android 11+, пакет `om.mgtrener.mgym`, код 18. Обновляйте APK поверх прежней установки из GitHub. Новая установка имеет пустой дневник.
