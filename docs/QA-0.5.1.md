# Проверки MGym 0.5.1

13.10.2026. Android UI-тест выполнялся только в изолированном пакете `.uitest`; пользовательское приложение и его дневник не очищались.

- 39 тестов JavaScript прошли. Включены 216 сочетаний возраста 16/35/65/90 лет, стажа, цели, срока и шага блинов; отдельно проверены 75 → 100 кг за 8 недель, 70 → 200 кг в жиме/приседе/тяге и перенос существующего плана с записанным занятием.
- Два целевых Android UI-теста на Pixel 7, API 37.1 прошли: форма создаёт план 75 → 100 кг, предупреждение выводится, сохранённый план содержит новый шаблон и контрольный ориентир; пересоздание экрана мигрирует старый расчёт и сохраняет копию перед миграцией. Отдельно проверен доступ к ключу копии через Android-хранилище.
- `:app:assembleDebug`, `:app:testDebugUnitTest`, `:app:lintDebug` прошли. Проверки синтаксиса JavaScript и `git diff --check` прошли.
- Итоговый APK имеет пакет `om.mgtrener.mgym`, версию 0.5.1 (16), min API 30, target API 37. Сертификат SHA-256 `400e333ea4893264eb2e674feb6a27257c0daed0646f37aa44dbe4be73699def` совпадает с опубликованным GitHub APK 0.5.0.

Эти тесты проверяют правила генератора и работу интерфейса, но не подтверждают достижение индивидуальной цели. Порог предупреждения о большом приросте — правило продукта. Нужны фактические тренировки, восстановление и, для максимальных попыток, оценка готовности спортсмена.
