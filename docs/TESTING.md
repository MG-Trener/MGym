# Проверки 0.2.0

30 сентября 2026, Pixel 7 / Android 17 (API 37).

- 12 JVM-тестов: расчёты, включение старых разминок, отсутствие бицепса в статистике и наградах, формат копирования, сравнение версий.
- 15 инструментальных тестов: SQLite, миграция 1→2, порядок подходов, резервные копии и совместимость настройки звука, разбор ответов обновлений, полные UI-сценарии. Все прошли.
- assembleDebug и lintDebug: успешны. Пять предупреждений о доступных версиях зависимостей, ошибок нет.
- Финальный APK: om.mgtrener.mgym, versionName 0.2.0, versionCode 4.

Первый запуск явно проверяет отсутствие тренировок и подходов в базе, отсутствие бицепса на экране. Добавление/редактирование жима, дробный вес, шаг веса, дополнительные поля. Отключение звука сохраняется после пересоздания Activity.

Десять подходов: перетаскивание пальцем, восстановление порядка, завершение, точный текст в Android clipboard, календарь год/месяц/день, интерактивный прогресс и рекорды. В APK нет тестовых данных: заполнение выполняется только кодом androidTest в отдельном package .uitest.

Обновления: проверены новая/текущая версия, некорректный ответ, prerelease, отсутствующий APK и посторонний адрес загрузки. Реальная установка будущей версии поверх 0.2.0 потребует следующего выпуска с тем же сертификатом. Громкость/ощущение звуков и вибрации следует оценить на физическом устройстве.

```powershell
.\gradlew.bat :app:connectedDebugAndroidTest -PmgymUiTestInstall=true
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

Тестовые пакеты удалены после проверки. Пользовательский дневник основного приложения не использовался. Во время повторного прогона был временный сбой ADB; итоговый прогон дал XML-отчёт с 15 tests / 0 failures / 0 errors. AGP не удаляет APK автоматически по кириллическому пути, поэтому тестовые пакеты удаляются явно.

Снимки: screenshots/bench/first-install.png, active.png, history.png, calendar-year.png, calendar-month.png, calendar-day.png, progress.png, records.png, settings.png. Первая установка пустая; остальные снимки сделаны на искусственных данных только в тестовом приложении.

Остаются проверки Android 11/12, физических телефонов, увеличенного шрифта и многолетних баз. Длинные списки прокручиваются внутри ограниченной области экрана.
