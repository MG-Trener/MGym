# MGym 0.2.6 — Путь к 150 кг

- На главном экране появилась кнопка «Путь к 150 кг». План охватывает 23 занятия до проверки результата 2–5 декабря 2026 года.
- Для каждого подхода можно сохранить фактический вес и число повторений; RPE доступен только для тяжёлых одиночных жимов и попыток.
- В настройках добавлен переход на опубликованный сайт с календарём и таблицами подходов.
- Прогресс плана хранится на устройстве и переживает обновление приложения. JSON-копия дневника пока не содержит записи плана.

Android 11 и новее. APK подписан тем же тестовым сертификатом, что и 0.2.5, и устанавливается поверх него с сохранением данных.
