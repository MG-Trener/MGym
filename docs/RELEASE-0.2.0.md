# MGym 0.2.0 — жим лёжа

- Только жим лёжа во всех рабочих разделах. Новая установка начинается с пустого дневника, без примеров и архивных записей.
- Исправлены нулевые показатели: все сохранённые подходы жима участвуют в расчёте, включая ранее отмеченные разминкой.
- Компактная история, копирование в буфер, перетаскивание подходов; календарь года и месяца с историей по дню.
- Интерактивные графики, рекорды и награды для жима.
- Анимации списка и формы, подсветка переключателей, подтверждение сохранения; отключаемые звуковые сигналы и вибрация.
- Ручная проверка новых версий через GitHub Releases, скачивание APK и установка через Android.

APK: **MGym-0.2.0.apk**, Android 11+. Тестовая сборка с прежним локальным сертификатом подписи. При первой установке записей нет; совместимое обновление поверх предыдущего APK сохраняет личный дневник. Контрольная сумма — SHA256SUMS.txt.
