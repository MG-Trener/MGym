# Обновления MGym

## Google Play

Магазинная release-сборка обновляется через Google Play; включение автообновления остаётся за пользователем. Проверки GitHub и их фоновые задачи отключены. В настройках есть кнопка страницы магазина.

GitHub Actions собирает и подписывает AAB при новом GitHub Release и может загрузить его только в черновик внутреннего трека. Увеличивайте versionCode/versionName, используйте соответствующий тег `vMAJOR.MINOR.PATCH`. Отдельный коммит сам по себе не меняет приложение на устройстве. Рабочую версию публикует владелец через Console после проверки.

[Подпись, доступ без JSON-ключа и порядок выпуска 0.7.1](GOOGLE-PLAY-0.7.1.md).

## APK из GitHub Releases

GitHubUpdateProvider запрашивает `https://api.github.com/repos/MG-Trener/MGym/releases/latest` по кнопке в настройках или из JobScheduler примерно раз в сутки при наличии сети. Фоновую проверку можно выключить в настройках. На Android 13+ для уведомления требуется системное разрешение. Тот же выпуск не показывается повторно; после следующего выпуска уведомление появится снова. Дневник не блокируется. Встроенных токенов и отправки тренировочных данных нет.

Версия берётся из BuildConfig. Выпуск должен быть стабильным, с тегом `vMAJOR.MINOR.PATCH` и ненулевым asset `MGym-MAJOR.MINOR.PATCH.apk`. Сравнение числовое; одинаковая/более старая версия не предлагается. URL допускается только из `https://github.com/MG-Trener/MGym/releases/download/`. Таймауты 10 секунд, ответ не более 1 МБ. Ошибки сети, 404, лимиты GitHub, отсутствующий APK и повреждённый ответ не выдаются за успешную проверку актуальности.

Кнопка «Скачать» и нажатие на уведомление открывают HTTPS asset в браузере. После загрузки пользователь открывает файл, разрешает установку из этого источника при необходимости и подтверждает установку Android. Приложение не устанавливает APK скрытно и не запрашивает REQUEST_INSTALL_PACKAGES. Подпись и совместимость проверяет системный установщик.

## Выпуск

1. Увеличить versionCode и versionName в app/build.gradle.kts.
2. Выполнить JVM, UI-тесты с `-PmgymUiTestInstall=true` и lint.
3. Собрать обычный APK без тестового флага. Проверить applicationId и сертификат.
4. Создать release с тегом версии и приложить APK с указанным именем, а также SHA256SUMS.txt.
5. Проверить публичный API latest и наличие скачиваемого asset.

Прежние GitHub-выпуски распространялись как debug APK с локальным сертификатом. Его необходимо сохранять вне Git; другой debug-ключ не сможет обновить эти установки. Новый upload key Google Play отличается: перед переходом сохраните JSON дневника и отдельный JSON планов. Не удаляйте приложение без обеих копий.

Новая установка не содержит записей. Обновление поверх совместимо подписанной версии сохраняет пользовательский дневник.
