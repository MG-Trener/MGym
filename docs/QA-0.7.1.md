# Проверка MGym 0.7.1

16 октября 2026 года. Последняя версия `origin/main` 0.7.0 включена перед подготовкой Google Play; устаревшая промежуточная сборка 0.6.2 в магазин не загружалась.

## Проверено

- 65 JavaScript-проверок Android-копии планировщика и 64 проверки сайта прошли. Сохранены наблюдаемый прогноз, автоматическая корректировка по подтверждённому факту/RPE, защита записанных подходов, удаление и восстановление планов.
- 15 JVM-проверок, lintRelease и подписанная сборка AAB прошли локально. `bundletool validate`, проверка подписи, манифеста и контрольных сумм подписанных записей AAB прошли. Нативные библиотеки всех четырёх ABI имеют выравнивание ELF LOAD не менее 16 КБ.
- На Pixel 7 / API 37.1 прошли шесть сценариев `BenchPlannerTest` и отдельно `PlayDistributionTest` в подписанной release-сборке с изолированным пакетом `.uitest`. Устаревшие ожидания номера шаблона и ручного применения нагрузки исправлены под поведение 0.7.0; производственный алгоритм не ослаблялся ради тестов.
- Release не отлаживаемый, cleartext и Android backup отключены; нет REQUEST_INSTALL_PACKAGES, POST_NOTIFICATIONS и фоновой задачи GitHub. В настройках доступны Google Play и email поддержки. Исходного плана в AAB нет.
- Локализация: 677 ключей, восемь языков, проверены параметры подстановки.
- [Проверка Android в GitHub Actions](https://github.com/MG-Trener/MGym/actions/runs/38869245730) прошла: Node, Python, JVM, lint и контрольный AAB.
- [Подписанная сборка и проверка доступа Google Play](https://github.com/MG-Trener/MGym/actions/runs/38869429403) прошли. GitHub получил временный токен, создал edit, прочитал треки и удалил edit, не меняя выпуск. Четыре Python-теста проверяют ограничения трека, последовательность validate/commit, очистку при ошибках и отсутствие commit у проверки доступа.
- Подпись артефакта CI совпадает с upload-сертификатом первого загруженного AAB. Секреты подписи настроены в environment `google-play`, постоянного Google JSON-ключа нет. Загрузка будущих выпусков включена и ограничена черновиком internal.
- Политика и поддержка сайта на русском/английском доступны с HTTP 200 и содержат info@mg-trener.com. Изменение контактов опубликовано поверх последней версии сайта с прогнозом и PDF, без отката её изменений.

## Google Play

В Console создано MGym, пакет `om.mgtrener.mgym`. Сохранены все 11 разделов начальной настройки, русская карточка, значок, обложка и четыре скриншота. Иконка и обложка помечены как созданные с помощью ИИ; скриншоты сняты с реального интерфейса тестовой установки.

AAB 21 (0.7.1) принят Google и опубликован во **внутреннем тестировании** для согласованного владельцем Google-аккаунта. Это не рабочая версия и не одобрение модерации. До первой проверки Google может показывать временное название `om.mgtrener.mgym (unreviewed)`.

В проверке выпуска нет блокирующих ошибок. Два предупреждения: отсутствует файл деобфускации (R8/ProGuard отключён) и дополнительные отладочные символы готовых нативных библиотек зависимостей. Оба относятся к будущей диагностике сбоев, не к отказу в загрузке.

Первый AAB загружен через Console. Автоматическая загрузка нового versionCode из GitHub выполнится при следующем выпуске; текущая проверка CI подтверждает сборку, подпись и доступ, но не выдаётся за повторную загрузку уже использованного versionCode.

## Остаётся перед рабочей версией

Установка внутренней версии пользователем, pre-launch report, проверка Android 11/больших шрифтов/TalkBack и обновления через магазин. Необходим закрытый тест: минимум 12 участников непрерывно 14 дней, затем заявка на production и модерация. Гарантировать одобрение Google нельзя.

Переход со старого debug APK требует предварительного сохранения двух JSON-копий (дневник и программы), поскольку сертификаты отличаются. Данные настоящей установки при проверках не очищались.
