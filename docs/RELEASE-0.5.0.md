# MGym 0.5.0 — восемь языков

- «Настройки → Язык приложения»: русский, английский, немецкий, французский, испанский, португальский (Бразилия), китайский (упрощённый), казахский и системный выбор.
- Переведены дневник, навигация, статистика, настройки, встроенный генератор трёх дисциплин и краткая методика. Переводы доступны без сети.
- Смена языка сохраняет историю, факты, планы и пользовательские заметки. Названия старых тренировок могут оставаться на языке их создания.
- Исправлена ошибка автоматического обновления старых расчётов; сохраняется исходная резервная копия.
- Исправлено сохранение факта одним нажатием при открытой клавиатуре.
- Добавлены лицензии компонентов в настройках, английские страницы поддержки/конфиденциальности и карточка Google Play.
- Подготовлен отчёт по 24 пунктам проверки. Публикация в Google Play требует завершения проверки аккаунта, upload-подписи, тестирования и анкет Console.

Android 11+, пакет `om.mgtrener.mgym`, code 15. GitHub APK обновляется поверх прежней версии с тем же сертификатом. Магазинный AAB не включает GitHub-проверку обновлений и пока не подписан upload-ключом.
