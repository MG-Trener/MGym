# Проверки MGym 0.5.0

13.10.2026. Проверялся только изолированный Android-пакет `.uitest`; пользовательский дневник не очищался.

## Результаты

- 15 JVM-тестов — успешно: статистика, версии, экспорт тренировки.
- 35 тестов JavaScript — успешно: генераторы, факты, пересмотр нагрузки, перенос дат, три дисциплины, резервные копии.
- 36 различных сценариев Android получили успешные результаты: 33 при полном прогоне; три первоначально неуспешных сценария проверены повторно после исправлений. Последний тест формы факта прошёл отдельно, с физическим нажатием при открытой клавиатуре и проверкой сохранения после пересоздания экрана.
- `LanguageTest`: восемь языков, неизменность подходов и пользовательской заметки, восстановление выбора, переключение на системный язык.
- Браузер на 360 × 800: восемь языков × создание жима/приседа/тяги, запись факта, перенос даты, перезагрузка, неизменность JSON, отсутствие горизонтального переполнения и ошибок JavaScript. У некириллических локалей не осталось русских фрагментов в проверенных основных сценариях. Казахский проверен отдельно как кириллический язык.
- Браузер сайта: фактическая миграция плана v2 → v3, прежнее занятие и целевая дата сохранены, исходная копия создана. Расчётные движки Android совпадают по SHA-256 с сайтом `a0d94a3dea9d58308c52bd72ba817f5dbf8e21b3`.
- Debug APK и release AAB собираются. Lint debug/release без ошибок; остаются предупреждения о более новых зависимостях, KTX и атрибуте локалей API 33 (для API 30–32 есть собственный выбор языка).
- APK: `om.mgtrener.mgym`, 0.5.0 (15), min API 30, target API 37. Сертификат SHA-256 `400e333ea4893264eb2e674feb6a27257c0daed0646f37aa44dbe4be73699def` — тот же, что у предыдущего GitHub APK.
- AAB: DEBUG=false, STORE_DISTRIBUTION=true, без POST_NOTIFICATIONS/RECEIVE_BOOT_COMPLETED/фоновой службы GitHub. Cleartext отключён. AAB пока unsigned.
- Все включённые `.so` имеют сегменты LOAD с выравниванием не менее 16 КБ. Android-прогон — эмулятор API 37.1 / 16 КБ.
- 572 ключа каталога: семь непустых переводов для каждого русского источника, параметры шаблонов проверены. Все языки включены в поставку, разделение языковых ресурсов отключено.
- Release-граф: 103 координаты с данными лицензий из upstream POM. Шаблоны приватных ключей/токенов в поставляемых исходниках и assets не найдены. Это проверка по шаблонам, а не гарантия отсутствия любого секрета.
- Страницы privacy-en/support-en доступны без входа на `https://mgym.mg-trener.com/`. Приложение использует прямой HTTPS, минуя старый перенаправляющий адрес GitHub Pages.

## Что исправили по результатам проверок

Устранены несовместимость регулярного выражения с Android ICU, двойное пересоздание экрана после выбора языка на Android 13+, присваивание `const` при миграции старого расчёта и сдвиг кнопки сохранения из-за потери фокуса/клавиатуры при касании. В тестах включён показ экранной клавиатуры, добавлено ожидание её открытия и прокрутка кнопки переноса даты перед физическим нажатием.

## Границы

Физические устройства Android 11–12, полный TalkBack, лингвистическая редактура носителями, Play pre-launch report, production-подпись, закрытое тестирование и анкеты Console ещё предстоят. Результаты не означают готовность «24/24» или одобрение Google Play.
