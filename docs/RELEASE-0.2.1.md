# MGym 0.2.1 — построчный ввод

- При старте тренировки сразу видна строка №1 с пустыми полями веса и повторений.
- Кнопка «+» расположена под последней строкой. Она сохраняет заполненный подход и добавляет следующую пустую строку.
- Пустые, неполные и некорректные значения не позволяют добавить новую строку.
- Незаконченный ввод восстанавливается после закрытия приложения.
- При завершении тренировки последняя заполненная строка сохраняется автоматически. Пустая строка в историю не попадает.
- Сохранённые подходы можно перетаскивать, удалять и редактировать нажатием на значение.

APK для Android 11+. Первая установка по-прежнему открывает пустой дневник. Обновление поверх совместимо подписанной версии сохраняет личные данные.
