# MGym 0.2.4 — таймер между подходами

- Вверху активной тренировки рядом со временем появился крупный секундомер отдыха.
- Таймер запускается вручную. Доступны пауза, продолжение и сброс.
- Отсчёт сохраняется при повороте экрана и повторном открытии активной тренировки; новая тренировка начинает с 00:00.

Android 11 и новее. APK устанавливается поверх 0.2.3 с сохранением дневника. Первая установка открывает пустой дневник.
