# MGym 0.2.3 — три движения и фоновые обновления

- С главной страницы можно начать отдельную тренировку по жиму лёжа, становой тяге или приседаниям. Для каждого движения ведутся свои история, графики, рекорды и статистика.
- Награды стали разнообразнее: первые и повторные тренировки каждого движения, регулярность по неделям, общий объём, вес и улучшение своего результата. Категории показаны компактно; одна тренировка не открывает большинство наград.
- Приложение примерно раз в сутки проверяет новый выпуск на GitHub при наличии сети и сообщает о нём уведомлением. Уведомления можно выключить в настройках; ручная проверка остаётся. Android попросит разрешение на уведомления. Нажатие открывает APK для скачивания, а установку подтверждает Android.
- В разделе «О MGym» указано, что приложение создано на энтузиазме спортсмена, бесплатно для всех желающих и работает без рекламы.

Android 11 и новее. Установите APK поверх 0.2.2: пакет и сертификат подписи сохранены. База обновляется с версии 2 до 3 с сохранением прежних подходов. Дневник остаётся на устройстве. Первая установка открывает пустой дневник.
