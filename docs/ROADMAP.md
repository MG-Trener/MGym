# План развития

## 0.2.0 — дневник жима

Только жим лёжа; пустая первая установка. Компактные таблицы, перетаскивание, календарь год/месяц/день, интерактивный прогресс, исправленный учёт всех подходов, JSON/CSV, звуки и анимации, обновления через GitHub Releases.

## До полноценной V1

- Проверки физических устройств, Android 11/12, большого шрифта и accessibility.
- Постоянный production signing key и окончательное решение по package ID.
- Пагинация, SQL-агрегаты и нагрузочное тестирование многолетней истории.
- Полный набор PR и события рекордов в календаре.
- История массы тела и относительная сила.
- Экспорт карточек наград и дополнительные способы анализа жима.

Демонстрационные тренировки в пользовательскую сборку не включаются.
Программы тренировок, авторегуляция, прогнозы и плато — отдельные последующие этапы. Облако и социальные функции добавляются только отдельным решением.
