# MGym 0.5.1 — исправление прогрессии в программах

- При исходном максимуме 75 кг и цели 100 кг за два месяца программа теперь меняет плановые веса, повторы и нагрузку по неделям. Каждая четвёртая неделя остаётся разгрузочной. Для новичков второе занятие недели отведено лёгкой технике.
- Цель 70 → 200 кг и другие запросы на большой прирост явно помечаются как неподтверждённые. Желаемый результат не подставляется в расчёт рабочих весов. Контрольный подход рассчитывается по текущей силе; обещания будущего максимума нет.
- Новые назначения учитывают возраст, стаж, восстановление, дату и шаг блинов. Пересмотр расчётной силы по-прежнему требует записанных тренировок и подтверждения пользователем.
- Старые персональные планы пересчитывают только будущие дни. Выполненные подходы и история поправок остаются. Перед пересчётом сохраняется доступная для экспорта копия.
- Методика в приложении поясняет границы прогрессии и критерий предупреждения: это прозрачное правило продукта, а не научно подтверждённый прогноз индивидуального результата.

Android 11+, пакет `om.mgtrener.mgym`, code 16. GitHub APK предназначен для обновления прежней установки из GitHub с тем же сертификатом. Локальный дневник и планы остаются на устройстве.
