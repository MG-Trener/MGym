# Локализация MGym

Языки: ru, en, de, fr, es, pt-BR, zh-Hans, kk. Выбор — «Настройки → Язык приложения»; доступно «Как в системе». Неподдерживаемый системный язык использует английский. Android 13+ также использует системные настройки языка приложения; Android 11–12 сохраняет выбор локально.

## Устройство

`localization/catalog.tsv` — UTF-8 каталог с разделителем `|`: русский источник и семь переводов в указанном порядке. `node tools/build-locales.cjs` проверяет уникальность, полноту и параметры `{0}`, затем создаёт каталоги для Kotlin и встроенного планировщика. После изменения исходника перегенерируйте оба каталога.

В Kotlin контролируемые подписи выводятся через `LocalizedText`/`Language.text`. Пользовательские заметки, ввод и имена сохранённых тренировок не переводятся. Канонические имена упражнений в базе и JSON остаются прежними: смена языка не создаёт новую дисциплину и не переписывает историю. Старое название тренировки, например «MGym / Жим», поэтому может остаться на исходном языке.

В WebView `i18n.js` переводит только представление. Не меняются значения полей и идентификаторы, названия пользовательских планов, алгоритмы и JSON. Генератор автономный: обращения к сервисам перевода отсутствуют. `tools/sync-bench-planner.cjs` после синхронизации сайта применяет `tools/localize-planner.cjs`; три файла расчётного движка остаются идентичны сайту.

Методика внутри приложения переведена в компактной форме. Ссылка на полную методику/исследования открывает русскую страницу и явно сообщает её язык. Публичные страницы конфиденциальности и поддержки доступны на русском и английском. Тексты лицензий распространяются в оригинале.

## Проверка

`LanguageTest` переключает все восемь языков при сохранённой тренировке, сравнивает данные до/после, проверяет повторное открытие и системный выбор. Только изолированный пакет `.uitest`.

Для UI-тестов с клавиатурой на эмуляторе включите показ экранной клавиатуры при подключённой аппаратной (`show_ime_with_hard_keyboard=1`). Тест ожидает открытия IME до физического нажатия; WebView-тест прокручивает кнопку в видимую область перед нажатием.

Браузерная проверка `tools/qa-localization.cjs` создаёт три программы, сохраняет факт, меняет целевую дату и перезагружает каждый язык при ширине 360 px; проверяет неизменность JSON и отсутствие горизонтального переполнения. Нужен Playwright (`PLAYWRIGHT_MODULE` при нестандартной установке) и Chromium (`CHROME_PATH` при необходимости).

Переводы требуют дополнительной вычитки носителями перед широким международным продвижением. Это не препятствует переключению языков и не скрывает ограничений расчёта.
