# MGym 0.6.1 — только свои планы

- Исходный фиксированный план убран. При первой установке планировщик пуст: создайте свою программу жима, приседаний или тяги. Вход в прежний план удалён.
- Заголовок планировщика изменён с MG150 на MGym.
- Возле выбора программы появилась кнопка «Удалить план». Подтверждение показывает название выбранной программы. Отмена ничего не удаляет.
- Удаляется выбранная программа с её записями в планировщике. Остальные программы остаются. Выполненные тренировки в дневнике Android сохраняются.
- Перед удалением автоматически сохраняется копия всех программ и результатов. «Мои данные» → «Копия до последнего удаления» позволяет сохранить JSON и восстановить его через импорт. При следующем удалении эта копия заменяется.
- После удаления последней программы планировщик снова пуст. Старые резервные копии совместимы, но не возвращают исходный фиксированный план в список.

Android 11+, пакет `om.mgtrener.mgym`, versionCode 19. Обновляйте поверх прежней APK-установки; подпись сохранена. Эти же изменения опубликованы на [сайте MGym](https://mgym.mg-trener.com/).
