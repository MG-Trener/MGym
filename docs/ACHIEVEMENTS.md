# Достижения

Achievements.evaluate — чистая функция от завершённых тренировок жима.
Порог количества: 1,10,25,50,100,250,500,1000.
Жим CLUB: 50,75,100,125,150,175,200 кг, по фактическому весу или e1RM. Все сохранённые подходы учитываются, старые типы больше не исключают записи.
Дата — первое завершение тренировки, удовлетворившей порогу. Повторная оценка не создаёт дубликаты.
Порог считается включительно. Незавершённые тренировки не открывают трофеи.
Награды пересчитываются после импорта; метаданные не хранятся как отдельные записи.
Иконки — собственная простая геометрия. Карточки для обмена изображением и остальные категории отложены.
