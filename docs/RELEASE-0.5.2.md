# MGym 0.5.2 — исправление длинных планов

- Если исходный результат старше 60 дней, облегчённый возврат занимает первые недели, а не всю программу. На примере максимума 75 кг и цели 100 кг за 19 недель рабочий вес изменяется с 45 кг до 62,5 × 3 к 18-й неделе; каждая четвёртая неделя остаётся разгрузочной.
- План не объявляет цель достижимой по одному старому результату. Нагрузка остаётся ниже исходной оценки силы, RPE ограничивает усилие, последующие назначения уточняются по выполненным тренировкам.
- Окно «О плане и расчёте» стало компактным: краткий итог, только важные предупреждения и ссылка на полную методику.
- Существующие планы получают новый расчёт только для будущих занятий. Записанные подходы сохраняются; перед обновлением создаётся новая резервная копия.

Android 11+, пакет `om.mgtrener.mgym`, код версии 17. APK предназначен для обновления установки из GitHub с прежним сертификатом. Новая установка начинает дневник с пустого листа.
