# MGym 0.7.1 · Google Play

16 октября 2026 года. Пакет `om.mgtrener.mgym`, versionCode 21, Android 11+, target API 37. Включены изменения 0.7.0: прогноз по фактическим тренировкам и автоматическая корректировка будущих весов по подтверждённым подходам и RPE. PDF-экспорт остаётся функцией сайта.

Приложение создано в [Play Console](https://play.google.com/console/u/1/developers/8281020327580560848/app/4974352155090566612/app-dashboard). Подготовка сборки не гарантирует одобрения Google; для открытой публикации требуется закрытое тестирование и модерация.

Версия 21 (0.7.1) опубликована во внутреннем тестировании для согласованного владельцем аккаунта. Все 11 разделов начальной настройки сохранены. [Отчёт проверок и ссылки на успешные сборки](QA-0.7.1.md).

16 октября подготовлен закрытый канал **Alpha** с той же сборкой 21 (0.7.1), доступностью для Казахстана, отдельным списком «MGym — закрытый тест» и каналом обратной связи `info@mg-trener.com`. После отдельного согласования владельцем пакет из 14 изменений отправлен на проверку; в Console подтверждён статус **«Изменения на проверке»**, предварительные автоматические проверки ещё выполняются. Одобрение и доступность закрытой версии пока не подтверждены. Полнота деклараций перепроверена: Play Console сообщает, что все декларации заполнены; для здоровья выбрана только категория «Тренировки и фитнес», дополнительные региональные требования отсутствуют. Дополнительно сохранён ответ об отсутствии рекламного идентификатора.

[Приглашение в закрытый тест](https://play.google.com/apps/testing/om.mgtrener.mgym) взято из Console. До одобрения и публикации закрытого выпуска доступность по нему не подтверждена. 16 октября создана [Google-группа MGym Beta Test](https://groups.google.com/g/mgym-mgtrener-beta), `mgym-mgtrener-beta@googlegroups.com`. Владелец согласовал общедоступное вступление без подтверждения; список участников, их email и публикация сообщений доступны только владельцу. В группу добавлены описание и приветственная инструкция. В настройках Alpha сохранён переход с email-списка на эту группу. С отдельного согласия владельца проверка перезапущена с новым способом доступа; в разделе «Изменения на проверке» подтверждено управление участниками через `mgym-mgtrener-beta@googlegroups.com`. Одобрение Google ещё ожидается. [Инструкция участникам и организатору](CLOSED-TESTING-RU.md).

## Обновления из репозитория

Release-сборка отключает проверки GitHub, фоновые задачи стороннего обновления и предложение установки APK. В настройках есть переход в Google Play. Для фоновых обновлений пользователь включает автообновление в магазине. Приложение не может принудительно включить эту настройку или гарантировать время установки.

Workflow `google-play.yml` собирает подписанный AAB при публикации GitHub Release или вручную. Для нового выпуска увеличьте versionCode/versionName и используйте соответствующий тег `vMAJOR.MINOR.PATCH`. Коммит в `main` сам по себе не обновляет приложение на устройствах.

Отправка разрешена только в `internal`; по умолчанию создаётся черновик без отправки на модерацию. Перевод в рабочую версию выполняет владелец в Console после тестирования. Служебный аккаунт не имеет production-прав.

## Подпись

Создан отдельный постоянный upload key, сохранённый в игнорируемой `.private/`. Пароль конфигурации зашифрован Windows DPAPI для текущего пользователя, доступ к каталогу ограничен владельцем Windows и SYSTEM. Ключ и пароли не включаются в репозиторий.

SHA-256 upload-сертификата:

`BF:B5:0A:52:9A:4A:76:12:99:58:11:2B:3A:05:19:AC:BB:36:F7:97:1C:96:A7:A7:FD:2A:FD:24:93:6C:09:30`

Локальная сборка: `tools/play-build.ps1`. Она задаёт четыре переменные подписи только текущему процессу и восстанавливает окружение после выполнения. Без подписи обычная release-сборка завершается ошибкой. Флаг `-PmgymAllowUnsignedBundle=true` предназначен только для проверки: такой AAB нельзя отправлять в магазин.

В environment GitHub `google-play` настроены секреты `MGYM_UPLOAD_KEYSTORE_BASE64`, `MGYM_UPLOAD_STORE_PASSWORD`, `MGYM_UPLOAD_ALIAS`, `MGYM_UPLOAD_KEY_PASSWORD`. Скрипт `tools/configure-play-signing-secrets.ps1 -Apply` передаёт их через стандартный ввод GitHub CLI без вывода значений. Временный файл ключа удаляется после сборки.

Владельцу нужна защищённая резервная копия ключа и пароля в своём хранилище: DPAPI-конфигурация привязана к текущему профилю Windows. Не передавайте ключи и пароли в чат.

## Доступ к Google без постоянного ключа

Отдельный Cloud-проект `mgym-releases`, номер 191649586136. Служебный аккаунт: `mgym-github@mgym-releases.iam.gserviceaccount.com`. Постоянных JSON-ключей Google нет; GitHub получает короткоживущий токен через Workload Identity Federation.

Provider: `projects/191649586136/locations/global/workloadIdentityPools/mgym-github/providers/github`.

Условие проверяет неизменяемые ID репозитория 1395944913 и владельца 196173122, ref `main` или `v*`, путь `.github/workflows/google-play.yml` и соответствие ref. На служебном аккаунте выдана только роль `roles/iam.workloadIdentityUser` для этого репозитория. Роли Cloud Editor/Owner ему не выдавались.

В Play Console разрешены просмотр информации MGym и выпуск его тестовых версий. Google не позволяет ограничить это право одним внутренним треком: технически оно также охватывает закрытые/открытые тесты. Владелец согласовал этот объём; код загрузки дополнительно допускает только `internal`. Прав на production, финансы, другие приложения, карточку и управление тестировщиками нет.

Переменные environment `google-play`: `GOOGLE_PLAY_WIF_PROVIDER`, `GOOGLE_PLAY_SERVICE_ACCOUNT`, `GOOGLE_PLAY_INTERNAL_STATUS=draft`. Отправку включает отдельная переменная **уровня репозитория** `GOOGLE_PLAY_PUBLISH_ENABLED=true`, только после первичного AAB в Console и проверки доступа.

Ручной запуск с `publish=false` проверяет подпись и доступ: временный edit создаётся, список треков читается, edit удаляется без изменения выпусков. При `publish=true` выполняется проверка versionCode, загрузка AAB, обновление только internal, validate и commit с `changesNotSentForReview=true`. При ошибке нет автоматического перехода к production или отправки на модерацию.

Новый черновик сохраняет предыдущий активный внутренний выпуск. Если в internal уже есть другой черновик, загрузка останавливается до его проверки или отмены владельцем; незавершённая работа Console не перезаписывается.

## Карточка и декларации

Поддержка: **info@mg-trener.com**. Категория «Здоровье и фитнес». Аудитория согласована владельцем: подростки от 14 лет и взрослые; группы Console — 13–15, 16–17, 18+. До 18 лет генератор требует сопровождения. Рейтинг IARC 3+/для всех оценивает содержимое и не меняет минимальный возраст генератора.

Сохранены политика конфиденциальности, отсутствие рекламы и ограниченного входа, IARC, аудитория, Data safety «данные не собираются/не передаются», отсутствие финансовых/государственных функций и Health apps declaration «Тренировки и фитнес».

Нет рекламы, аккаунтов, платных функций, Health Connect, геолокации и аналитических SDK. Профиль и дневник обрабатываются на устройстве, Android backup отключён. Экспорт выполняется по действию пользователя. Внешние страницы и средства связи работают отдельно по собственным правилам.

## Прежние установки из GitHub

Старый debug-сертификат отличается от нового upload key и ключа Play App Signing. Прямое обновление прежнего APK через Google Play может быть невозможно. Перед переходом сохраните **JSON дневника и отдельный JSON программ**, убедитесь в наличии обеих копий и восстановите их в магазинной установке. Не удаляйте старую установку без копий. Автоматической синхронизации сайта и Android нет.

## Перед открытой публикацией

1. Проверить установку из внутреннего трека, pre-launch report и обновление следующей совместимо подписанной версии поверх первой.
2. Отдельно проверить Android 11, большие шрифты и TalkBack. Текущие инструментальные проверки выполнялись на Pixel 7 / API 37.1.
3. Набрать минимум 12 настоящих участников закрытого тестирования непрерывно минимум на 14 дней. Внутренние тесты этот этап не заменяют.
4. Подать заявку на доступ к рабочей версии, затем отправить выпуск на проверку. Решение принимает Google.
