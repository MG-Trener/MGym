# Проверка MGym 0.6.1

13 октября 2026 года. Сайт и APK используют один расчёт и одинаковую функцию удаления плана.

- JavaScript: 54 теста сайта и 56 тестов Android-копии прошли. Проверены пустой старт, импорт прежней копии с `active: original`, удаление активной/неактивной программы, смена текущей программы дисциплины, сохранение других журналов и удаление последнего плана.
- На Pixel 7, API 37.1 прошли все шесть тестов `BenchPlannerTest`: создание, миграция, факт с открытой клавиатурой, пересмотр, импорт, изменение расписания, пустой старт, отмена удаления, удаление, перезапуск и восстановление. После удаления реальная тренировка остаётся в SQLite-дневнике. Отдельный повтор проверки подтвердил компактный диалог удаления высотой до 440 CSS px.
- Отдельный запуск `PlannerDiaryTest` прошёл: перенос прежних записей, сохранение упражнений, отсутствие дубликатов, откат некорректной записи и миграции SQLite. Использовался только изолированный пакет `.uitest`; данные основной установки не очищались.
- В боковом браузере проверены пустое состояние, создание двух программ, отмена, удаление одной, сохранность другой после обновления страницы, удаление последней и скачивание автоматической копии. Скачанный JSON содержит удалённый план. Ошибок JavaScript не обнаружено.
- Итоговые `:app:assembleDebug`, `:app:testDebugUnitTest`, `:app:lintDebug` прошли. Обычная сборка выполнена без тестового идентификатора.
- Новый текст удаления проверен для всех языков каталога; названия пользовательских программ не переводятся.
- Исходный план не загружается ни сайтом, ни WebView. В APK сохранена только приватная таблица соответствия старых записей для переноса исторического факта в дневник; её адрес запрещён WebView.
