# MGym 0.4.0 — три дисциплины

- Вместо трёх отдельных кнопок старта — разделы жима, приседа и становой тяги. В каждом понятная кнопка своего плана, самостоятельная тренировка и история.
- Генераторы приседа и тяги с отдельными исходными результатами, техникой, дозировкой и подсобными упражнениями. Новые иллюстрации сплит-приседа, сгибания ног и ягодичного моста.
- Текущие планы согласуют соседние нагрузки приседа и тяги; второе близкое занятие становится лёгкой техникой. Записанные дни сохраняются. Самостоятельная работа вне планов пока не включена в это согласование.
- Факты всех трёх дисциплин попадают в историю, включая частичную подсобную работу. SQLite v5 сохраняет предыдущие данные.
- Прогресс и календарь разделены по движениям. В прогрессе фильтры «Все / По плану / Самостоятельно», средний фактический RPE рабочих подходов.
- В настройках пояснено, что отзывы и предложения можно писать в WhatsApp; вознаграждение разработчику полностью добровольно.
- Добавлены политика конфиденциальности и подготовка release AAB для Google Play. Release-вариант получает обновления через магазин; GitHub APK сохраняет прежний канал обновлений.

Устанавливайте APK поверх предыдущей версии без удаления. Перед сменой канала подписи сохраните обе JSON-копии. Копии с приседом и тягой требуют MGym 0.4.0 или обновлённого сайта; прежний генератор жима не должен их пересчитывать.

Публикация в Google Play ещё не выполнена: нужны аккаунт, production/upload-подпись и проверка магазина. Для iPhone подготовлен план переноса, приложения iOS пока нет.
