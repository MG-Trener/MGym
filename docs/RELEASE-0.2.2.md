# MGym 0.2.2 — редактирование истории

- В завершённой тренировке появилась кнопка «Редактировать»: исправление веса, повторов, RIR/RPE и комментария, добавление пропущенных и удаление ошибочных подходов.
- Редактирование доступно из истории и месячного календаря. Последний подход защищён от удаления, дата тренировки сохраняется. Статистика и текст копирования учитывают исправления.
- Кнопки копирования и редактирования расположены в отдельных строках компактного заголовка.
- В настройках добавлены контакт разработчика Михаила Гаврилычева и кнопка WhatsApp: +7 701 870 93 84.

Android 11 и новее. Установите APK поверх MGym 0.2.1: пакет и сертификат подписи сохранены, схема базы не менялась. Удалять приложение перед обновлением не нужно. Первая установка по-прежнему открывает пустой дневник.

Версия 0.2.2, versionCode 6. APK собран локально из main тем же ключом, что 0.2.1; ключ не передаётся в репозиторий. Проверка обновлений в приложении использует этот GitHub Release.
