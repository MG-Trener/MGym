**Актуальная подготовка: [MGym 0.7.1](GOOGLE-PLAY-0.7.1.md).** В ней описаны созданное приложение в Console, постоянная upload-подпись и доступ GitHub без JSON-ключа.

Ниже сохранена историческая запись подготовки 0.5.0. Её статус, инструкция о неподписанной сборке и незаданном email устарели; для выпуска используйте документ 0.7.1.

## Архив: подготовка MGym 0.5.0

## Статус

Подготовлены release-вариант приложения, Android App Bundle, тексты карточки, графика, политика конфиденциальности и сценарий проверки. Отправка в Play Console не выполнялась. Аккаунт зарегистрирован и оплачен; со слов владельца ожидается проверка личности. Без upload-подписи и настройки Play App Signing собранный unsigned AAB не является готовым файлом для загрузки.

Пакет: `om.mgtrener.mgym`. Версия: 0.5.0 (15). Android 11+, target API 37. Release-вариант отключает GitHub-обновления и их фоновые задачи/уведомления; debug APK остаётся способом обновления прежних установок из GitHub. Не загружайте debug APK в Google Play.

## Что нужно сделать владельцу

1. Завершить регистрацию и проверку аккаунта Play Console. Проверить доступность имени пакета и создать приложение MGym.
2. Выбрать хранение ключа подписи через Play App Signing и создать отдельный upload key. Хранить ключ и резервную копию у владельца, вне Git. Пароли не передавать в чат.
3. Настроить переменные окружения `MGYM_UPLOAD_STORE` (абсолютный путь), `MGYM_UPLOAD_STORE_PASSWORD`, `MGYM_UPLOAD_ALIAS`, `MGYM_UPLOAD_KEY_PASSWORD` на машине сборки. Затем выполнить из корня репозитория `./gradlew :app:bundleRelease` (Windows: `gradlew.bat`). При отсутствии всех четырёх значений сборка остаётся неподписанной. Результат: `app/build/outputs/bundle/release/app-release.aab`.
4. Проверить подпись через `jarsigner -verify -verbose -certs`, а сертификат сопоставить с upload key в Console. Не использовать текущий debug-ключ как производственный.
5. Заполнить карточку из `store/listing-ru.md и store/listing-en.md`, контактный email владельца, категорию Health & Fitness, страны распространения, возрастную аудиторию и анкеты. Email пока не задан: его нельзя заменять вымышленным адресом.
6. Указать политику: https://mgym.mg-trener.com/privacy.html и поддержку: https://mgym.mg-trener.com/support.html. Проверить доступность обеих страниц без входа.
7. Пройти внутренний тест, затем требуемый аккаунтом закрытый тест. Для новых личных аккаунтов Google требует минимум 12 участников непрерывно 14 дней; после этого отдельно запрашивается доступ к production. Наличие тестеров и одобрение не обеспечиваются сборкой.
8. Проверить pre-launch report, работу на Android 11 и актуальной Android, большие шрифты, TalkBack, импорт/экспорт, обновление поверх предыдущего подписанного выпуска, отсутствие потери истории.
9. После проверки подать выпуск на модерацию. Одобрение магазина не гарантируется.

## Подпись и прежние установки

GitHub APK подписан прежним локальным debug-сертификатом. Новый production-сертификат Google Play может не позволить обновить его поверх. До перехода в магазин сохраните JSON дневника и отдельный JSON программ. После установки магазинной версии восстановите оба файла. Не удаляйте старую установку без проверенных копий. История и планы хранятся локально, облачная синхронизация отсутствует.

## Анкеты: исходные данные для заполнения

- Без рекламы, регистрации, аккаунтов и платных функций. Доступ проверяющему не требует логина.
- Данные спортсмена и тренировок обрабатываются на устройстве. Рекламных/аналитических SDK, Health Connect, геолокации и доступа к контактам нет. JSON/CSV экспортируются только по действию пользователя в выбранное место.
- Для Data safety проверьте итоговый release AAB: отсутствие передачи тренировочных данных разработчику позволяет заявлять отсутствие их сбора приложением. Внешние страницы и WhatsApp работают по собственным правилам; не копируйте ответы анкеты без проверки итогового состава SDK.
- Заполнить Health apps declaration: приложение содержит фитнес-планы и журнал. Приложение не является медицинским изделием, не диагностирует, не лечит и не предотвращает заболевания. Медицинские вопросы адресуются специалисту.
- Возрастные поля генератора не заменяют декларацию целевой аудитории и контентный рейтинг магазина. Для 14–17 лет предусмотрено сопровождение; аудиторию окончательно заявляет владелец с учётом требований Google и выбранных стран.
- Вознаграждение добровольно; платёжного механизма, ссылки на оплату, покупки функций и подписки в этой версии нет. При добавлении платежей потребуется отдельная проверка правил магазина.

## Сценарий для проверяющего

Открыть «Тренировки» → выбрать движение → открыть его план → создать программу → сохранить факт → вернуться в историю. Повторное сохранение обновляет запись. В «Прогрессе» выбрать движение, источник записей и метрику. В настройках проверить конфиденциальность, экспорт, контакты и удаление данных.
