# Лицензии и происхождение материалов

Проверка: 13.10.2026, releaseRuntimeClasspath MGym 0.5.0.

- `runtime-licenses.json` содержит 103 координаты, включая транзитивные platform/BOM-записи: название лицензии и URL исходного POM. Все указанные компоненты — Apache License 2.0. Для Guava listenablefuture 1.0 учтена лицензия родительского POM.
- Полный текст Apache 2.0 и перечень компонентов включены в `app/src/main/assets/licenses/NOTICE.txt` и доступны в «Настройки → Лицензии компонентов» без интернета.
- AndroidX — Android Open Source Project; Kotlin/kotlinx.coroutines — JetBrains и авторы; Guava — Guava Authors; JSpecify — JSpecify Authors. Отдельных рекламных, аналитических и crash-reporting SDK в release-графе зависимостей нет.
- Приложение использует системные шрифты; файлы сторонних шрифтов не распространяются.
- Иллюстрации подсобных упражнений созданы генерацией изображений для этого проекта. Их наличие не является заявлением об исключительных правах или медицинской точности. Использованы собственные графические материалы проекта для иконки и карточки магазина.
- Этот документ относится к включённым компонентам и материалам. Он не назначает лицензию всему исходному коду MGym.

При обновлении зависимостей повторно сверить license/NOTICE в исходных пакетах и обновить перечень. Сведения POM и этот технический аудит не заменяют юридическую оценку при споре о правах.
