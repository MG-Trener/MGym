# MGym · 0.2.2

Компактный Android-дневник **жима штанги лёжа**. Первая установка открывает пустой дневник: никаких демонстрационных тренировок, подходов или архивной истории в APK нет.

[Скачать APK](https://github.com/MG-Trener/MGym/releases/latest) · [Репозиторий](https://github.com/MG-Trener/MGym)

## Возможности

- Построчный ввод: пустая строка №1 → вес и повторы → «+» под строкой → пустая строка №2. Новая строка доступна только после корректного заполнения предыдущей. Последняя заполненная строка сохраняется при завершении; незаконченный ввод восстанавливается. RIR/RPE и комментарий доступны при редактировании сохранённого подхода.
- Добавление, редактирование и удаление подходов в активной тренировке. Завершённую тренировку можно снова открыть в режиме «Редактировать»: добавить пропущенный подход, исправить вес, повторы, RIR/RPE и комментарий, удалить ошибочный подход и переставить строки пальцем за ≡.
- Компактная история и копирование тренировки в буфер обмена.
- Годовой и месячный календарь; нажатие дня открывает историю.
- Интерактивный график e1RM, веса, объёма и повторений; периоды и рекорды.
- Все сохранённые подходы учитываются в объёме и повторениях. Старые отметки «разминка» больше не исключают записи из статистики. e1RM рассчитан только для 1–12 повторений.
- Награды за тренировки жима и силовые показатели.
- Плавная перестановка строк, раскрытие формы, подсветка вкладок и подтверждение сохранения. Короткие звуки и вибрация отключаются независимо; беззвучный режим телефона отключает звук.
- JSON backup, восстановление и CSV. Настройки звука/вибрации входят в JSON.
- Настройки → «Проверить обновления»: GitHub Releases, скачивание APK в браузере и установка через Android.

Дневник хранится локально. Сеть используется только для ручной проверки обновлений; тренировки не отправляются на сервер. Регистрации и рекламы нет.

## Android Studio

Открыть эту папку с `settings.gradle.kts`, дождаться Gradle Sync, выбрать встроенный JBR и запустить `app`. Нужен Android 11+ (API 30), compile/target SDK 37. Kotlin, Jetpack Compose, SQLiteOpenHelper. iOS не поддерживается.

```powershell
$env:JAVA_HOME = 'C:\Program Files\Android\Android Studio\jbr'
$env:GRADLE_USER_HOME = Join-Path $env:USERPROFILE '.gradle'
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
# Инструментальные тесты — ТОЛЬКО изолированное приложение:
.\gradlew.bat :app:connectedDebugAndroidTest -PmgymUiTestInstall=true
# После тестов восстановить обычный APK:
.\gradlew.bat :app:assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. Пакет: `om.mgtrener.mgym`.
Путь проекта содержит кириллицу; `android.overridePathCheck=true` и `file.encoding=COMPAT` сохраняют работу Gradle на текущей Windows-машине.

## Данные

SQLite schema v2. Обновление 1→2 сохраняет записи и добавляет порядок подходов. В 0.2.0 новой миграции схемы нет.
Старая пользовательская история бицепса не показывается ни в одном рабочем разделе и не влияет на награды/прогресс жима; она сохраняется только для совместимости ранее созданных JSON-копий. Старый активный сеанс только с бицепсом закрывается, освобождая возможность начать жим. Данные не поставляются вместе с приложением.

JSON format v1 обратно совместим; CSV содержит текущий дневник жима. Импорт заменяет дневник после подтверждения, в транзакции. Android cloud backup отключён. Перед переустановкой используйте экспорт.

## Обновления и публикация

[Правила выпуска и подписи APK](docs/UPDATES.md). Текущий APK — тестовая сборка, подписанная локальным Android debug-ключом для совместимости с предыдущими тестовыми установками. Ключи и пароли в Git не входят. Для обновления поверх установленного приложения нужны тот же package и сертификат подписи; APK с другим ключом Android не установит поверх существующего.

[Проверки](docs/TESTING.md) · [База](docs/DATABASE.md) · [Аналитика](docs/ANALYTICS.md) · [Архитектура](docs/ARCHITECTURE.md)

Длинные списки прокручиваются внутри экрана; число видимых строк зависит от размера экрана и системного шрифта. Программ тренировок, прогнозов и определения плато пока нет.
