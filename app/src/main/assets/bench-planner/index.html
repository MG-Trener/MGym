    Своя программа

    Адаптивная программа: 1–4 занятия в неделю, от 2 недель до 2 лет. Возраст 14–100 лет; до 18 и после 85 — только с индивидуальным сопровождением. Без фармакологии и бустеров. Цель не гарантируется.

    Спортсмен и срок
    От какого результата считать

    Не нужно проверять максимум ради анкеты. Подойдёт чистый рабочий подход; результат без паузы уточняется по контрольным подходам.

    Расписание и оборудование

    Выберите 1–4 доступных дня. Соседний день после тяжёлого жима будет лёгким; при ограниченном восстановлении объём уменьшается.

    Предварительный расчёт

      Сохранится отдельная программа с этими датами. Предыдущие планы и их результаты останутся в списке.

      Мои данные

      Планы и результаты хранятся в MGym на этом устройстве. Через неделю откроется тот же календарь. Пропущенные тренировки не переносятся автоматически.

      Удаление приложения или его данных удалит программы. Сохраните отдельную копию программ. Этот JSON совместим с сайтом: перенос выполняется через файл, автоматической синхронизации нет. Прежние записи из MGym 0.2.6 доступны кнопкой «Прежний план и записи». Копия дневника в настройках не включает программы генератора.

      Результат тренировки

      Заполняйте только сделанные подходы. Пустое поле — нет записи. Килограммы указаны как общий вес; для гантели — вес одной гантели.

      Проверка нагрузки

      Меняются только будущие незаписанные тренировки. Расписание, прошедшие дни и фактические подходы сохраняются. Повторно одна тренировка не учитывается.

      Изменить цель и расписание

      Изменятся только будущие дни без записей. История, частичные записи и сегодняшнее назначение сохранятся.
